One funny line for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f):
a single sentence, at most 200 characters, on any subject — with the surprise
saved for the end.

- `main.py` — the entrypoint: writes the line to `/output/entry.txt`.

## The line

> I only picked up my phone to check the time, and according to my screen
> time report, that took six hours.

105 characters, one sentence. Setup: picking up the phone just to check the
time. Twist: the screen-time report says that took six hours — an everyday
truth everyone recognises, with the punchline landing on the last words.
